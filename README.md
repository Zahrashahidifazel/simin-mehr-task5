# 📖 سیمین مهر | SIMIN MEHR

> **هر محصول، یک داستان...** ✨

فروشگاه آنلاین هنر اصیل ایرانی با محوریت محصولات دست‌ساز، هدایای معنوی و محصولات فرهنگی — همراه با مجله‌ای اختصاصی برای روایت داستان‌های پشت هر اثر.

پروژه‌ای **کاملاً فرانت‌اند** و سبک، بدون وابستگی به فریم‌ورک یا بک‌اند، که همه‌ی منطق فروشگاه (سبد خرید، علاقه‌مندی‌ها، سفارش‌ها، نظرات و خبرنامه) را با `localStorage` مدیریت می‌کند.

---

## ✨ ویژگی‌ها

### 🛒 بخش فروشگاه
- نمایش محصولات با **Skeleton Loading** (تجربه‌ی بارگذاری نرم)
- **جستجوی زنده** بر اساس عنوان محصول
- **فیلتر بر اساس دسته‌بندی** (مذهبی و معنوی / هنر ایرانی / سبک زندگی)
- **مرتب‌سازی** بر اساس قیمت (صعودی/نزولی) و محبوبیت
- افزودن به **سبد خرید** با مدیریت تعداد و ذخیره‌سازی پایدار
- **لیست علاقه‌مندی‌ها** (Wishlist)
- **داشبورد کاربری** برای مشاهده تاریخچه سفارشات
- **فرآیند تکمیل سفارش** با فرم اعتبارسنجی‌شده و انتخاب روش پرداخت
- نمایش وضعیت **موجودی** و برچسب‌های ویژه (پرفروش / جدید / تخفیف)

### 📄 صفحه محصول
- جزئیات کامل محصول با تصویر، قیمت، تخفیف و توضیحات
- **سیستم امتیازدهی و نظرات** (با توزیع ستاره‌ای و فرم ثبت نظر)
- نمایش **محصولات مشابه** در همان دسته‌بندی
- انتخاب امتیاز با **ستاره‌های تعاملی**

### 📖 مجله سیمین مهر
- صفحه فهرست مقالات با **فیلتر دسته‌بندی** و مقاله‌ی ویژه (Featured)
- صفحه‌ی جزئیات مقاله با ساختار بلوک‌محور (تیتر، متن، نقل‌قول، پاراگراف مقدماتی)
- **مقالات مرتبط** در پایان هر مقاله
- دکمه‌های **اشتراک‌گذاری** (کپی لینک، توییتر، تلگرام)
- باکس معرفی **نویسنده** و تگ‌های مقاله
- پیش‌نمایش ۳ مقاله‌ی آخر در صفحه اصلی فروشگاه

### 🎁 قابلیت‌های جانبی
- **خبرنامه** با اعتبارسنجی ایمیل، جلوگیری از ثبت تکراری و صدور کد تخفیف `WELCOME10`
- **Toast Notification** برای بازخورد بصری همه‌ی اقدامات
- طراحی **کاملاً ریسپانسیو** با `dir="rtl"`
- انیمیشن‌های نرم (Hover, Skeleton, Modal, Toast)
- **ذخیره‌سازی پایدار** همه‌ی داده‌ها در `localStorage`

## 🚀 اجرا

چون پروژه به صورت کاملاً استاتیک کار می‌کند، فقط کافی است یک سرور محلی راه‌اندازی کنید (به دلیل استفاده از `URLSearchParams` و فایل‌های تصویری، باز کردن مستقیم با `file://` توصیه نمی‌شود):

```bash
# با Python
python -m http.server 8080

# یا با Node.js
npx serve .

# یا با Live Server در VS Code
```

سپس مرورگر را باز کنید:
```
http://localhost:8080/index.html
```

## 🗄️ ساختار داده (localStorage)

همه‌ی اطلاعات کاربر در کلیدهای زیر ذخیره می‌شوند:

| کلید | توضیح |
|------|--------|
| `siminMehrCart` | آیتم‌های سبد خرید |
| `siminMehrWishlist` | شناسه‌های محصولات علاقه‌مندی |
| `siminMehrUser` | اطلاعات کاربر وارد‌شده |
| `siminMehrOrders` | تاریخچه سفارشات |
| `siminMehrReviews` | نظرات کاربران (بر اساس شناسه محصول) |
| `siminMehrSubscribers` | ایمیل‌های عضو خبرنامه |

> برای ریست کامل داده‌ها: `localStorage.clear()` را در Console مرورگر اجرا کنید.

## 🧠 معماری کد

`app.js` به دو ماژول منطقی تقسیم می‌شود:

### ۱) ماژول فروشگاه
- مدیریت State مرکزی (`allProducts`, `cart`, `wishlist`, `currentUser`, ...)
- توابع کمکی: `formatPrice`، `renderStars`، `showToast`، `getAvatarColor`
- منطق سبد، علاقه‌مندی، داشبورد، نظرات و پرداخت
- شبیه‌سازی API با `fetchProductsAPI()` (Promise + `setTimeout`)

### ۲) ماژول مجله
- آرایه‌ی `mockArticles` با ساختار بلوک‌محور (Schema-Driven Content)
- رندر داینامیک صفحات مجله و مقاله
- سیستم مسیریابی بر اساس `slug` از URL

هر صفحه به‌صورت **شرطی** مقدار‌دهی می‌شود؛ یعنی یک فایل `app.js` همه‌ی صفحات را مدیریت می‌کند:

```js
document.addEventListener('DOMContentLoaded', () => {
    if (document.getElementById('products-grid')) loadProducts();
    if (document.getElementById('product-detail')) initProductPage();
    if (document.getElementById('articles-grid')) initMagazinePage();
    if (document.getElementById('article-detail')) initArticlePage();
});
```
